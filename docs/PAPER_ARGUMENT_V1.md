# Paper argument V1 (offline scaffold)

This is a logical scaffold, not a claim that the current calibration has
established the full story. Each statement is labeled by evidential status.

## 1. Problem

**ALREADY EMPIRICAL / PRIOR WORK:** behavioral diversity and routing structure
are not equivalent to acquired functional specialization. The project therefore
asks what microscopic task ecology could make history-dependent comparative
advantage possible.

## 2. Construct-validity control

**ALREADY EMPIRICAL:** GF(7) coefficient worlds are an exact mechanistic
control, but vary one affine operation family. They are not sufficient evidence
for broad semantic roles. The earlier behavioral society result remains a
separate descriptive observation.

## 3. Transfer geometry

**DERIVED DESIGN:** define a directed source-to-target learning matrix `L` and
designed latent-overlap matrix `G`. A specialization-capable ecology should
provide measurable diagonal learning plus non-flat transfer/interference. The
current control manipulates `G` in a fixed exact-verifier OPE substrate.

## 4. Controlled semantic ecology

**FUTURE EMPIRICAL TEST:** GLOBAL, BLOCK, and DIAGONAL share the same semantic
families and output classes but tie run-specific procedural parameters
differently. Natural exposure is primary; greedy teaching is an upper-bound
control; foreign-theta is a specificity control.

## 5. Effective stability theory

**DERIVED IN EFFECTIVE MODEL:** centering `P` removes the generalist direction;
`T(L)=P L.T D_rho P` controls niche-contrast modes in the explicitly stated
competence-sensitive dynamics. Its eigenvalue threshold is a result of that
model, not an LLM theorem.

## 6. Falsifiable future prediction

**FUTURE HYPOTHESIS:** if a measured ecology has weak centered spectrum, a
future society should remain comparatively generalist under moderate
competence-sensitive allocation. If BLOCK has a dominant block mode, early
functional competence contrasts should align with it. If DIAGONAL has
near-degenerate modes, independent societies may choose different agent-label
assignments while preserving ensemble symmetry.

## 7. What remains untested

The transfer calibration does not establish roles, routing alignment, useful
division of labor, persistence, finite-capacity effects, or a causal mapping from
`L` to an LLM society. Those require a separately reviewed, preregistered next
phase and must not be inferred from HSE or from a toy trajectory.

## Adversarial objections to retain

- `G` may correlate with template/surface similarity rather than reusable latent
  procedure.
- Five environment seeds are a pilot-level replication unit, not powered
  population inference.
- Balanced output labels do not eliminate baseline difficulty or answer-prior
  differences.
- Teaching may reveal the latent rule more directly than ordinary interaction;
  natural transfer is therefore the decisive ecology result.
- Foreign-theta can distinguish generated parameter reuse only if semantic
  family and nuisance structure are genuinely matched.
- Projection by `P` is a modeling choice, not observed finite capacity.
- `T` is not automatically an LLM-society Jacobian.
