# Ecological Information Geometry V3 — offline report

## Executive result

This phase used zero external model calls and US$0.00 external spend. It asks a
narrow prerequisite question: does the generated task ecology itself contain the
predictive transfer geometry that its GLOBAL/BLOCK/DIAGONAL labels claim?

The V3 Bayes instrument is intentionally not an LLM result. It passed the
pre-registered information/locality/learning sanity gates on the deterministic
synthetic ecology, with the Monte Carlo draw count recorded in
`reports/task-ecology/ecological-information-v3/v3_manifest.json`. The old OPE
generator audit is reported separately and remains construct-validity evidence,
not a repaired society experiment.

The run used 2,000 deterministic prior draws per cell. A 100-draw benchmark was
about 14 seconds and extrapolated 10,000 draws to a locally impractical runtime;
2,000 is the protocol's stated minimum when 10,000 is computationally
prohibitive. The exact independent-cell zeros and all geometry definitions do
not rely on Monte Carlo noise.

The machine-readable source is `v3_geometry_summary.csv`; values below are
generated from that file, not hand-entered:

|---|---:|---:|---:|---:|---:|
| GLOBAL | 0.9912 | 0.9912 | 0.0000 | 0.8619 | 0.0000 |
| BLOCK | 0.9910 | 0.3303 | 0.6607 | 0.8616 | 0.5744 |
| DIAGONAL | 0.9913 | 0.0000 | 0.9913 | 0.8620 | 0.8620 |

At h=0 all joint outputs are uniform over eight classes and component accuracy
is 0.5. Information and Bayes gain grow monotonically with the nested natural
history horizon in the exact learner. The result is the expected prior-induced
geometry: dense GLOBAL transfer, within-block transfer, and near-zero
cross-family DIAGONAL transfer.

The optional greedy teaching control reaches `J_normalized=1.0` and
`L*=0.875` at h=8 in all three geometries, compared with the natural values in
the table. This is a positive control for informative exposure, not the primary
ecology estimand.

The `v3_gates.csv` file contains every criterion and status. The component
sanity gate compares within-condition component spread, not baseline-vs-learned
gain (learning gain is intentionally large here).

## What this establishes — and what it does not

Established offline: the V3 generator has 64 valid cases per family, six
balanced maps, no semantic theta/geometry leakage, exact factor locality, an
explicit prior, a reproducible Bayes posterior, and a measurable `G -> J ->
L*` hierarchy. The independent cells are zero by construction and are checked
analytically.

Not established: that DeepSeek can infer the maps, that natural language
surface forms induce the intended skill, that a society develops roles, that
`L*` is a model upper bound, or that a social Jacobian follows the effective
operator. The V3 ecology is synthetic and deliberately easier to verify than
the previous OPE ecology.

## Retrospective V2 finding

The old generator did not implement the simplest interpretation of its labels:
GLOBAL shared threshold/compatibility but not exception; BLOCK shared only the
first two factors inside each pair; DIAGONAL had family-unique factors. The
10,000-seed collision sweep, complete 768-case functional agreement, factor
influence, and h=1/2/4/8 natural identifiability are in the four `old_*.csv`
tables. The old result should therefore remain a mechanistic/null control and
not be described as a clean functional-specialization ecology.

## Decision gates

All V3 gates are software/audit gates, not evidence about a language model. A
future LLM ecology would still require a small, single-agent calibration with
held-out tasks, objective scoring, foreign-theta controls, and natural exposure
before a private/shared society experiment. No Gate 2 is authorized here.

## Strongest caveats

1. The uniform balanced-map prior is an instrument choice, not a pretrained
   model prior.
2. The semantic rendering is procedural and synthetic; surface plausibility is
   not functional realism.
3. Natural histories are the primary target; teaching is only a diagnostic and
   must not be used to rescue a weak ecology.
4. The finite empirical V2 information audit uses only five frozen environments;
   it is descriptive and not a population estimate.
5. Information `J` is not useful specialization. Utility, allocation, and
   complementarity remain separate downstream questions.
