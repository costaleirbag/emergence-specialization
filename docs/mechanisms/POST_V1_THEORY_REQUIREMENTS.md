# Requirements exposed by the post-V1 decomposition

## Measurement-aware correction (2026-08-13)

These additions constrain interpretation of the existing requirements; they do
not define replacement equations or Theory V2.

1. `A_bit` and `A_joint` must be treated as distinct observables. Use `A_bit`
   for specialization/Psi and `A_joint` for calibration of a router updated by
   exact joint correctness.
2. Any directional specialization-growth decomposition must use independent
   probe halves or an explicitly calibrated measurement-error model. The naive
   same-measurement terms are validation quantities, not latent mechanisms.
3. Reliability, role-direction cosine, AB/BA disagreement, and seed-clustered
   uncertainty must be reported before assigning a persistent-role or churn
   interpretation. Undefined cross-half energies remain undefined.
4. Probe-count adequacy is part of construct validity. The current eight-probe
   regime is marginal; hypothetical adequacy curves are design diagnostics,
   not imputed evidence.
5. Sharing must be represented as both overlap/provenance and update-rate/FIFO
   timescale. The arithmetic timescale effect is not, by itself, a competence
   mechanism.
6. Router staleness and memory-state insufficiency remain descriptive
   hypotheses until construct-correct, held-out, seed-clustered prediction or
   intervention identifies them.

The previous requirements below remain historical constraints. The new
measurement-aware analysis downgrades the old churn interpretation and does not
replace any Theory V1/V1.1 equation.

This is not Theory V2 and contains no replacement equations. It is a constraint
list for any future formalization, if the principal researcher decides one is
warranted.

1. A future model must distinguish current held-out competence from cumulative
   router belief. In the clean data, endpoint A–mu alignment is weak and split-
   half A reliability is low, so this requirement must include an explicit
   measurement-error/reliability treatment.
2. A future model must represent FIFO memory as a state with age and provenance,
   not only as a scalar homogenization factor. At q=0, q=.5, and q=1 the
   displayed memory age and exact-case overlap differ sharply.
3. A future model must allow competence changes that are orthogonal or opposite
   to the current role direction. Across both ecologies, Delta-Psi is generated
   by positive innovation/churn while the reinforcement term is negative on
   average.
4. A future model must separate exposure-to-memory transmission from
   memory-to-competence transmission. Exposure and memory count interactions are
   substantial, while memory-to-current-competence predictive performance is
   weak in held-out seed tests.
5. Any use of a local K must state its domain of validity and test transport to
   social memory states. The present distance audit does not establish a strong
   local-extrapolation failure, so this cannot be assumed as the explanation.
6. Complexity must earn its place by improving held-out social-seed prediction.
   The registered M0–M4 ladder did not show robust improvement from recency,
   slot order, pair interactions, or the tiny tree ceiling.
7. A future theory must be evaluated against reliability ceilings and seed-
   clustered uncertainty; agent×niche×probe rows cannot be treated as independent
   confirmation.

These are empirical constraints, not proposed dynamics. Theory V2 remains
undefined.
