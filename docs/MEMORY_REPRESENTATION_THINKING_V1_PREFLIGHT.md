# memory-representation-thinking-v1 preflight

**Status: preflight passed; real calibration authorized by the session request.**

## Frozen design

- Same `deepseek-v4-flash` model and DeepSeek Direct backend as clean v2.
- Reasoning factor uses the documented DeepSeek V4 API toggle: `thinking.type`
  is `disabled` for `off` and `enabled` with `reasoning_effort=high` for `high`.
  The same model ID is used in both conditions. See the official [DeepSeek API
  completion reference](https://api-docs.deepseek.com/api/create-chat-completion)
  and [thinking-mode guide](https://api-docs.deepseek.com/guides/thinking_mode).
- Memory factor changes only serialization: `full_experience` retains the
  current eight-field experience record; `feedback_only` retains only world,
  x, y, and displayed correct answer.
- No reasoning trace is inserted into memory or persisted as a memory field.
- Balanced held-out probes: 14/world, exactly two examples for each answer label
  0–6. Probe hash: `7c5370122b553dafbd1ef950f3b4de9ca9636f7c3922cb31800169638b59c2df`.
- Ten context seeds/world, nested k values `[0,1,2,4,8]`, three exact-prompt
  replicates.
- k=0 is one common representation-free baseline per reasoning mode, reused
  analytically for both labels.
- True corrupted feedback exists only for feedback-only k=8 and is generated by
  `(true_label + 1) mod 7`; each displayed label differs from its own truth.
