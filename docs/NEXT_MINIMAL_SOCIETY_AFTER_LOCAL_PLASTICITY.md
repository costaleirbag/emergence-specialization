# Next Minimal Society After Local Plasticity

**Design only. Not executed.** Principal-researcher review is required before
any model calls.

The local-plasticity gate passed: same-niche natural experience improved exact
competence and exceeded equally sized independent foreign context. The minimal
next hypothesis is now:

> Does competence-sensitive allocation amplify initially accidental
> agent–niche differences into persistent functional organization?

## Proposed society

- four initially exchangeable agents;
- same DeepSeek Direct model and neutral V2 semantic prompt;
- four V3.1 DIAGONAL niches;
- empty host-controlled memories;
- natural task stream and exact verifier;
- no assigned roles or family labels in prompts;
- competence-sensitive confidence routing as the adaptive condition.

## Causal controls

1. adaptive routing + private memory;
2. random routing + private memory;
3. adaptive routing + shared memory;
4. optionally, round-robin + private memory.

The first comparison should be small and paired by seed. It must not optimize
HSE or select conditions after looking at results.

## Primary outcome

Measure whether adaptive private allocation amplifies early competence
differences more than controls. Track competence matrices `A(t)`, absolute
competence, routing allocation, team utility, and across-seed label symmetry.
`Phi(t)`, task-agent MI, utilization entropy, matching gain, and HSE are
secondary diagnostics; HSE alone is not specialization.

The finite-system symmetry criterion is both:

- within-run functional asymmetry;
- across-run permutation symmetry of agent labels.

Do not call this a thermodynamic phase transition.

## Required preflight before execution

- freeze exact config and seed pairing;
- preserve the local-plasticity commit and probe hash;
- verify no prompt-level role/identity leakage;
- test private/shared memory semantics with mocks;
- preregister stopping, health, cost, and retry rules;
- keep the cross-domain transfer track separate.

This document does not authorize execution.
