## Protocols and execution records

The `*_PREREGISTRATION.md`, `*_LOG.md`, `*_EXECUTION_LOG.md`, and
`*_PREFLIGHT.md` files are frozen or operational records. They are not
automatically scientific conclusions. The corresponding report is the place to
read the result; the recorded run, manifest, and source commit are the places
to audit provenance.

## Historical and superseded material

Superseded analyses remain in place with an explicit notice. In particular,
`MINIMAL_DEVELOPMENTAL_SOCIETY_V1_REPORT.md` is retained for chronology and is
not the canonical repaired analysis. Original invalid derived outputs are
preserved under the ignored local report tree and are referenced by the repair
report.

The root [presentation working note](../Emergent%20Specialization%20Presentation.md)
is preserved as a historical presentation artifact; it is not the canonical
scientific report.
