# Theory V1 epistemic data ledger

Theory V1 establishes a one-way boundary between development data and future
tests. Existing observations informed the theory and therefore remain
**DEVELOPMENT**, even when technically valid. New microscopic observations may
only parameterize quantities already present in the frozen equations. New
social trajectories become **CONFIRMATORY** only after parameters and all
predictions are sealed.

| Dataset / phase | Category | Permitted use | Status |
|---|---|---|---|
| GF(7), OMP pilots, private/shared pilots, memory and representation calibrations | DEVELOPMENT | Motivation, diagnostics, historical comparison | legacy |
| V3/V3.1 ecology geometry and observation audits | DEVELOPMENT | Defines the frozen ecology and its offline Bayes reference | established offline |
| Learner calibration V1/V2, relation/cross-domain controls | DEVELOPMENT | Learner bottleneck context; no prospective Theory V1 confirmation | partial |
| Local Plasticity Curve V1 | DEVELOPMENT | Microscopic motivation; not an independent Theory V1 test | qualified legacy gate |
| Minimal Developmental Society V1 and repaired analysis | DEVELOPMENT | Social motivation; not Theory V1 confirmation | partial organization |
| Theory V1 MICRO campaign | PARAMETERIZATION | Estimate `K^(4)`, `K^(8)`, `K^(12)` only | **CONSUMED / DEVELOPMENT-FOR-V2** |
| Aborted serial Theory V1 MACRO attempt | TECHNICAL_ABORT / QUARANTINED | Throughput and infrastructure diagnostics only | never include in scorecard or scientific estimates |
| Restarted Theory V1 MACRO campaign | CONFIRMATORY | Test sealed predictions T1–T9 | **CONSUMED / DEVELOPMENT-FOR-V2** |
| Theory V1.1 Stage A harness validation | INSTRUMENT VALIDATION | Validate the neutral output instrument only | pending |
| Theory V1.1 MICRO campaign | PARAMETERIZATION | Estimate frozen `K^(4)`, `K^(8)`, `K^(12)` under clean harness | pending |
| Theory V1.1 targeted MACRO campaign | CONFIRMATORY | Test four preregistered clean-harness V1 mechanism questions | pending |

The canonical Theory V1 evaluation is the deterministic forensic reconstruction
performed after the MACRO run. The equations and thresholds were frozen before
MACRO; implementation defects in the prediction/scorecard layer were discovered
afterward and repaired without changing raw observations or equations. The
repair is therefore a forensic evaluation, not a claim that the repaired code
was prospectively sealed. Neither prospective dataset may be reused as
independent confirmation of a future Theory V2.

No existing dataset is silently promoted to confirmation. If a future Theory V2
is written, all Theory V1 prospective data become DEVELOPMENT for that later
theory.
