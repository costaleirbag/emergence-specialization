# Advisor brief: information geometry before another society run

The previous OPE geometry control specified parameter sharing but did not first
show that the generated task ecology supplied a corresponding predictive
transfer geometry. The new offline instrument inserts that missing layer:

`designed G -> predictive information J -> ideal decision gain L* -> model transfer -> society dynamics`.

V3 uses four procedural families and a fully auditable 3-bit verifier. GLOBAL,
BLOCK, and DIAGONAL have exact latent-sharing priors. The natural-history Bayes
analysis is the primary result; teaching is only an upper-bound/positive control.

The decision gate is conservative: if natural h=8 information, diagonal
learning, locality, or ordered Bayes complementarity fail, the next LLM task
ecology should not be launched. A pass would establish an ecology-level
precondition, not spontaneous specialization. A fail is scientifically useful:
it says the ecology should be redesigned before spending model calls.

The current V3 ecology is deliberately symbolic and may still be too easy or
too artificial. Any future semantic ecology must be calibrated as a single-agent
transfer problem first, with held-out tasks, objective scoring, balanced
difficulty, and a measured directed transfer matrix.
