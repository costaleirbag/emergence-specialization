# Autonomous research final brief

## 30-second result

Private memory reliably produces more **behavioral differentiation** than
shared memory in the clean 2x2, and that contrast survives several HSE distance,
linkage, bootstrap, and probe-deletion checks. It still does not establish
functional specialization. The main microscopic failure is not mathematical
identifiability: truthful `k=8` contexts determine the GF(7) rules exactly, but
the model shows no non-alias held-out learning gain. With the rule explicitly
provided, AR-001 achieves 153/168 correct (0.911), although a post-run audit
found that all its probes had `x=0`; this is a one-dimensional execution control,
not a complete affine test.

The strongest reframing is therefore: **under what task-transfer ecologies does
private history become acquired comparative advantage rather than merely a
different behavioral state?**

## Biggest results, falsifications, and ambiguity

- **Biggest empirical result:** the private/shared behavioral-HSE endpoint gap is
  robust across all tested HSE definitions and probe perturbations.
- **Biggest falsified idea:** lack of GF(7) identifiability is not the main `k=8`
  failure. Exact modular aliases also explained much of the apparent old
  same-world accuracy gain.
- **Biggest remaining ambiguity:** whether private histories causally create
  anchor-biased phenotypes, or whether some competence signal is hidden by weak
  probes and memory/exposure confounds.

## Microscopic mechanism

Functional chain:

`examples` -> **rule identifiable: strong at k8** -> **model induction: failed /
weak in frozen protocol** -> **explicit execution: strong on x=0 slice, full 2D
unresolved** -> **competence-confidence link: weak** -> **useful allocation:
not demonstrated**.

Competing pathway:

`memory` -> **contextual anchor: plausible, not causal** -> `response bias` ->
**shared synchronization/private divergence: observationally compatible**.

## Current interpretation of clean v2

Clean v2 establishes developmental behavioral differentiation conditioned on
information locality. It does not establish acquired world competence, aligned
routing, or useful division of labor. Shared and private also differ in prompt
exposure: shared displays eight recent labels with mean age 3.5, while private
usually displays fewer, older experiences. Those are mechanistic components of
the treatment, but they prevent attributing the contrast specifically to label
anchoring.

## Theory, robustness, and literature

The two-state theory separates competence from contextual response bias. The
new ecology extension defines a causal directed transfer matrix

`L_cd(h) = improvement on d after exposure c - matched placebo improvement`.

An ecology must first show learnability and non-flat/asymmetric/interfering
transfer; only then can routing turn exposure differences into comparative
advantage. This connects Taskonomy-style measured transfer to gSCAN/CLUTRR-style
generated exact verifiers. Recent spontaneous-role work makes “identical agents
form roles” alone a weak novelty claim; the stronger hypothesis is that transfer
geometry predicts organization and collective utility. See the bounded primary-
source notes for limitations.

## What we can claim

1. Private information locality is associated with more behavioral diversity
   than shared locality in this frozen ecology, robust to tested HSE choices.
2. Behavioral diversity can coexist with little demonstrated functional
   competence or routing alignment.
3. GF(7) `k=8` examples are generally identifiable, but the model did not show a
   clean non-alias learning gain under the frozen thinking-off renderer.
4. Explicit one-dimensional modular execution is comparatively reliable.

## What we cannot claim

- that anchoring causes the HSE contrast;
- that agents acquired useful ALPHA/BETA/GAMMA/DELTA specializations;
- that HSE is competence or division of labor;
- that AR-001 validates general bivariate affine execution;
- that a semantic ecology will improve emergence;
- that the ecology-to-organization framing is novel without a fuller review.
