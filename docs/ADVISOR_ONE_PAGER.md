# Advisor one-pager: from behavioral diversity to ecology-dependent roles

## Question

When initially exchangeable LLM agents accumulate different histories, does the
system produce only different behaviors, or acquired comparative advantages that
support useful division of labor?

## Extension beyond static routing diversity

The source routing work treats behavioral diversity largely as a property of a
given society. This project studies `B(t)`: whether routing plus feedback locality
changes the society over time. The current refinement makes the task ecology an
experimental variable rather than a neutral backdrop.

## What clean v2 established

Across confidence and random routing, private feedback produced higher endpoint
behavioral HSE than shared feedback. The contrast is robust to multiple HSE
distances/linkages, 1,000 probe bootstraps, and every leave-one-probe-out check.
It did not produce comparably strong competence differentiation, routing
alignment, or useful matching gain.

## What microscopic calibration established

GF(7) k8 examples are generally rank-full and symbolically identify the rule.
After removing modular aliases, memory exposure did not improve held-out
accuracy. AR-001 showed 91.1% execution when the rule was explicit, but only on
the historical `x=0` probe slice. Thus lack of identifiability is not the main
failure; induction/representation is weak, and full bivariate execution remains
partially open.

## Is HSE competence?

No. HSE is a robust measure of behavioral differentiation here, but current
data show that it can rise while competence and useful allocation remain weak.
That separation is now a result, not an inconvenience to hide.

## Best current mechanism

Different private contexts plausibly maintain different response biases, while
shared contexts synchronize them. This is compatible with the data but not yet
causally identified because shared/private also changes memory volume, coverage,
and recency. “Anchoring causes HSE” remains a hypothesis.

## Ecology reframing

All four current worlds are coefficient instances of the same affine-modular
operation. They are a strong mechanistic/null ecology and a weak sole substrate
for broad functional roles. Define a directed causal transfer matrix `L_cd(h)`:
held-out improvement on family d after exposure c, relative to placebo. A
specialization-capable ecology needs positive learnability plus non-flat,
asymmetric, block, or interfering transfer under capacity constraints.

## Experiment that could establish functional specialization

First validate generated procedural families with exact interpreters and a
randomized single-agent transfer matrix. Only if targeted exposure creates
retained, task-local comparative advantage should the private/shared society
experiment be repeated. The first paid gate can be a 48-call two-family screen;
the immediate next action is offline design and verifier review at US$0.
