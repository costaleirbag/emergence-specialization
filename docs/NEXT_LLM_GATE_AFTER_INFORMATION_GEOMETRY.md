# Next LLM gate (proposed only)

This document does not authorize an experiment. It is a proposal conditional on
the V3 audit passing all critical gates and on separate principal-researcher
review.

1. Freeze a small, held-out, single-agent calibration using the V3 verifier or a
   separately approved semantic/procedural ecology.
2. Measure natural and forced-exposure transfer with no endogenous routing.
3. Check baseline balance, run-specific/foreign-theta specificity, and the full
   directed transfer matrix.
4. Only then consider a society-level private/shared replication.

GF(7)/OPE remains a mechanistic/null control, not evidence of functional roles.

## V3.1 observable-geometry learner calibration (proposed only)

This gate is conditional on all O1--O10 in
`reports/task-ecology/ecological-information-v31/gate_summary.json` passing.
It is not a society experiment. Use the frozen semantic renderer, natural h=8
histories, a small fixed seed set, and the three geometry contrasts. Target
approximately 500--1,500 logical calls, subject to a separate cost preflight.

Measure realized `L^DeepSeek` against `J_obs` and `L*_obs`. Report false
transfer in DIAGONAL and missed transfer in GLOBAL, without treating either as
an ecology failure. Do not launch private/shared routing until this learner
calibration is reviewed.
