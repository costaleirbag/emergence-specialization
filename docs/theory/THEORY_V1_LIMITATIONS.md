# Theory V1 limitations

Theory V1 is a finite-system effective model, not a universal law. Its main
limitations are the local linearity assumption, mean-field FIFO retention,
uniform niche frequencies, four-agent/four-niche scale, one provider/model,
stochastic LLM responses, and two synthetic ecologies. `K` is a response
operator measured under a particular prompt and memory renderer; it may vary
with context length, semantic parsing, and target distribution.

The model predicts formation, not useful exploitation. Team utility, matching,
routing alignment, and HSE remain secondary diagnostics. A supercritical
`R_spec` is a property of the explicit effective matrix, not evidence that a
real LLM society has an instability. A failed ecology or weak learner may make
some tests non-identifiable without falsifying every mechanism.

No Theory V2 is defined here. Any correction after prospective data requires a
new frozen theory and an independent test set.
