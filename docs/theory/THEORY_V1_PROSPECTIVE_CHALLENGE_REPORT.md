## Epistemic design

All previous experiments are DEVELOPMENT data. Future MICRO observations would
only parameterize `K^(k)`. Predictions would be sealed before future MACRO
observations, which alone would be CONFIRMATORY. This boundary has not been
crossed.

The model and assumptions are recorded in [THEORY_V1_FROZEN.md](THEORY_V1_FROZEN.md)
and [THEORY_V1_DERIVATION.md](THEORY_V1_DERIVATION.md). The tests validate

## What was and was not predicted

No social data were collected, so T1–T9 are all `NOT RUN`, not failures and not
passes. The implementation is designed to generate the sealed scorecard only
after independent K estimates and before macro observations.

## Strongest limitation

The fixed design is large relative to the original budget. That historical
operational block was resolved only by an explicit budget-only amendment and a
new protocol seal; it is not evidence for or against Theory V1. The design was
not shrunk, and any future change in budget, scale, or calls still requires
principal-researcher review and a new protocol seal.
