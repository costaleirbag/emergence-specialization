# Theory V1 prospective challenge report

## Executive verdict

**BLOCKED BEFORE PAID INFERENCE.** Theory V1 was frozen and validated offline,
but the unchanged 212,480-call design exceeds its US$6.25 ceiling once the
required 30% safety margin is applied. No prospective data exist.

## Epistemic design

All previous experiments are DEVELOPMENT data. Future MICRO observations would
only parameterize `K^(k)`. Predictions would be sealed before future MACRO
observations, which alone would be CONFIRMATORY. This boundary has not been
crossed.

## Frozen mathematical model

The model and assumptions are recorded in [THEORY_V1_FROZEN.md](THEORY_V1_FROZEN.md)
and [THEORY_V1_DERIVATION.md](THEORY_V1_DERIVATION.md). The tests validate
centering, `Psi_spec`, K reconstruction, retention, matched effective routing
gain, spectral classification, and deterministic call accounting.

## What was and was not predicted

No social data were collected, so T1–T9 are all `NOT RUN`, not failures and not
passes. The implementation is designed to generate the sealed scorecard only
after independent K estimates and before macro observations.

## Strongest limitation

The fixed design is large relative to the current budget. This is an operational
block, not evidence for or against Theory V1. Any future change in budget,
scale, or calls requires principal-researcher review and a new protocol seal;
this session does not shrink the scientific design.
