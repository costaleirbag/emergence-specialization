# Next Step After Cross-Domain Transfer Bottleneck V1

**Decision: do not run a society.** The learner gate is partial and the frozen
population does not identify two of its planned contrasts (BLOCK cross-block and
DIAGONAL cross-domain). The next step is a cheap mechanistic diagnostic, not a
larger social experiment.

## Supported diagnosis

The ladder shows:

```text
natural history -> canonical history       = substantial improvement
canonical history -> explicit rule table   = very large improvement
semantic target -> canonical target        = small improvement once rule is given
```

The leading hypothesis is a bottleneck in extracting a reusable executable
policy from resolved examples. This is not proof that the model lacks rule
induction. It is a hypothesis constrained by the observed ladder.

## Cheapest discriminating follow-up (design only)

Use the same semantic ecology and a single fresh calibration seed, with no
society, no routing, and no prompt tuning after results. Compare only a small
mechanistic set:

1. natural eight examples (the current A2 representation);
2. the same examples rendered as a compact canonical input/output table;
3. a held-out rule-execution probe with a single output component;
4. an equivalent target with a paraphrased evaluation template.

The purpose is to separate:

- multi-example rule induction;
- joint three-component composition;
- semantic parsing of the target;
- context/order interference.

This proposal must be separately preregistered and costed. It must not be used to
retrofit the current result or to authorize a society run.

## Protocol repair required before a geometry qualification rerun

The next learner gate should add the missing cells explicitly:

- BLOCK: true-SAME within-block and true-INDEPENDENT cross-block pairs;
- DIAGONAL: true-SAME cross-domain positive-control pairs or a predeclared
  off-diagonal learner-induced-transfer design;
- an independently frozen empty-memory baseline for each geometry/seed/target;
- enough held-out probes to estimate the planned contrast, while retaining the
  environment seed as the scientific unit.

No such repair is executed in this repository state.

## Closed questions

- No society, routing, feedback, intervention, or Gate 2 was run.
- No extra seeds or model calls were added after seeing the ladder.
- A3/A4 are diagnostic positive controls, not evidence of natural learning.
